# 别穿帮灯光助手 V3

给学生、摄影组和灯光组使用的本地灯光连续性工具。它把上一镜、当前现场、相机曝光和真实灯具资料合在一起，最终输出可直接执行的：

- 灯具品牌与型号
- 建议功率档位及可执行范围
- 建议色温与 CTO/CTB 色纸
- 灯到人物距离
- 人物目标照度
- 环境光补光或控光目标
- 数据可信度和资料来源

## 本地运行

```bash
npm install
npm run dev
```

打开：[http://localhost:3002](http://localhost:3002)

生产模式：

```bash
npm run build
npm run start
```

## 使用流程

1. 可选：上传“上一镜”和“现在现场”两张照片。
2. 确认两张照片使用相同相机曝光，并锁定白平衡。
3. 选择品牌和型号，可使用搜索快速找灯。
4. 设置灯到人物距离、灯高、柔光附件和环境照度。
5. 在右侧读取最终功率、色温、环境补光和可信度。
6. 保存项目、场次和镜号；需要换电脑时导出 JSON 备份。

照片只在当前浏览器中分析，不上传。保存镜次时只保存分析数值，不保存照片原图。

## 灯具数据

当前 V3 数据库包含 75 个可选型号、15 个品牌分类，包括爱图仕、amaran、南光、神牛、金贝、智云、优篮子、斯莫格、COLBOR、NEEWER、影器、永诺和 SWIT 等。最后一类“自定义灯具”用于覆盖暂未收录的品牌和型号。

数据分为三档：

- `官方资料`：有厂商页面或官方手册链接，并记录测试距离、色温和附件。
- `品牌数据库`：有明确照度值，但当前版本尚未绑定可点击的官方来源。
- `估算资料`：资料不完整，按同灯型功率效率估算，只作为起始档位。

产品不会把三类数据混成同一种“精确值”。最终指令会同时显示可信度和功率范围。

## 1%—100% 调光差异

产品提供三种处理方式：

- `灯内 Linear`：先在支持的灯具菜单中选择 Linear，再按线性光输出计算。
- `原厂默认/未知`：给出明确的起始档位，同时扩大建议范围。
- `本机实测校准`：录入 25%、50%、75% 三个档位相对100%的实测输出，系统分段插值。

没有测光条件时，不要求逐灯实验；使用官方100%数据和保守范围即可。片场最终仍建议用入射式测光表在人物脸前复核。

## 照片分析口径

- 浏览器支持 FaceDetector 时自动识别面积最大的人脸。
- 不支持时使用左、中、右人物区域，并允许用户确认位置。
- 亮度计算在线性 RGB 中完成，人物区域与环境区域分开统计。
- 图像色温仅用于两张同曝光、锁白平衡照片之间的连续性起点，不能替代专业色温表。

## 精度与公式

人物目标照度采用入射式测光关系：

`E = C × N² / (ISO × t)`

其中标准球形测光头常数使用 `C=340`，快门时间由帧率和快门角度计算。灯具输出还会叠加测试距离、灯高、柔光和色纸损耗、色温段光效、灯具数量及调光曲线。
